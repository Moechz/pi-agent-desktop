Pi Agent Desktop 定制版（0.8.8-custom）安装说明
================================================

一、安装
  双击 Pi-Agent-Desktop-Custom-Setup-0.8.8.exe，确认提示后等待完成。
  无需管理员权限（安装到当前用户 %LOCALAPPDATA%\Programs\pi-agent-desktop）。

二、首次运行被 Windows 拦截（SmartScreen）怎么办？
  本安装包未做代码签名，首次运行可能提示"已保护你的电脑"：
  点击"更多信息" -> "仍要运行"即可。
  （若右键 exe -> 属性 -> 勾选"解除锁定"更省事）

三、与官方版的区别（本版特性）
  1. 内置 7 组界面定制（会话只留结果、输入框边框、侧边栏分组+状态点+折叠箭头、
     DSH 字体、+New 按钮、弹窗不透明、图标加大）。
  2. 已禁用自动更新：官方更新会覆盖界面定制，故本版不检查更新。
     如需回官方版：先卸载本版，再从官方 GitHub 下载原版安装。

四、卸载
  开始菜单搜索"卸载"，或在系统设置-应用中找 "Pi Agent Desktop (定制版)"。
  卸载保留会话/聊天数据（位于 %APPDATA%\..\Roaming 对应目录）。

五、许可
  基于 Chasen-Liao/pi-agent-desktop（MIT License）官方 0.8.8 构建，
  仅修改了界面渲染产物；原许可文件随包分发（安装目录内）。
